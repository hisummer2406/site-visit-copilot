# 05 · 楼盘数据源调研

> 版本 v0.1 · 2026-09-15 · 状态：桌面调研结论（基于公开信息检索）
> 结论先行：**国内没有公开、合法、稳定的"楼盘资料 API 端口"，能拿到的都是分层、有价、有坑的。**

## 1. 渠道全景

| 渠道 | 能拿到什么 | 获取方式 | 价格锚点 | 坑 |
|---|---|---|---|---|
| 商业数据库（克而瑞 CRIC、中指 CREIS） | 楼盘级数据最全：土地、成交、供应、户型、价格；CRIC 覆盖 367 城 | 按端口订阅，无开放 API | 广州城壹 2025 年采购克而瑞全年 9.68 万；易居披露单端口约 4600 元/年；中指历史报价全库 5 万/年、单区域 2 万/年 | 只卖账号不卖 API，一个端口一个坐席 |
| 门户页面（贝壳/链家/安居客/房天下） | 挂牌价、户型图、小区信息、去化描述 | 无官方 API；技术上可爬（GitHub 有成熟爬虫项目） | 免费 | **商用有法律风险**（贝壳有反爬及诉讼先例，页面结构常变）；自用研究属灰色地带 |
| 政府公开数据（住建局网签、统计局 70 城房价、土地招拍挂公告） | 成交量价、供应、土地成交价 | 免费公开 | 免费 | 颗粒度粗：只有量和价，无楼盘级产品细节 |
| 国外 API（ATTOM / Zillow Bridge / Reonomy 等） | 美国房产数据，API 体系成熟 | 开放 API | $74–数百/月 | **只有美国数据，对本项目无用** |

## 2. 关键判断

**爬得到的都不值钱，值钱的都爬不到。**

- 端口能拿到的都是客观数据层：均价、成交量、容积率、户型面积——公开数据人人可得，不构成壁垒
- 考察真正值钱的是主观情报层：四代宅阳台做法业主买不买账、示范区动线设计逻辑、去化快慢的真实归因——**这些在任何数据库里都不存在**
- 这个判断反向验证了考察资产化的价值：公开数据人人都有，自有考察库才是壁垒

## 3. 应对设计：分层背景包

不找"一个端口替代考察"，而是分层拼装：

```
考察前背景包 = 客观数据层（AI 自动预填）      +  主观情报层（自有库调取）
               均价/成交量/容积率/土地历史          历次考察结论/亮点判断/对标意见
               来源：政府数据 + 门户公开页          来源：自己的批次纪要
               人到现场只需核实                    人到现场补充增量
```

隐性好处：硬指标考察前自动预填好，人到现场只做"核实 + 补主观判断"，采集负担进一步降低。

## 4. 落地建议

1. 客观数据层先从**政府网签数据 + 土地招拍挂公告**做起（免费、合法、稳定）
2. 门户数据做补充：仅限自用研究、不对外售卖数据，风险可控
3. 若未来产品化对外卖：届时购买克而瑞单区域端口（2 万/年量级）做合规底座
