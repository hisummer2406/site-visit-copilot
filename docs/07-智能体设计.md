# 07 · 智能体设计

> 版本 v0.1 · 2026-09-15 · 状态：讨论稿
> 前置阅读：[02-方案设计讨论稿.md](02-方案设计讨论稿.md)（讲"做什么"），本文讲"智能体本身怎么设计"。

## 0. 设计立场（三条，决定一切架构选择）

1. **表格是记忆，智能体是加工车间，批次是工作单元。** 智能体尽量无状态，持久状态全部放在智能表格与批次控制表里。模型升级、换平台、换供应商，资产和状态都不动——客户不被锁死。
2. **价值在"催"，不在"答"。** 被动应答的智能体三个月就没人用了；它的灵魂是主动性——催关批、催确认、提醒"这批还没出纪要"。
3. **分寸感是产品体验的核心。** 它混在考察群里，刷屏一次信任就没了。只在关键节点说话。

## 1. 单智能体五层架构（基础形态）

### 感知层 · 四种触发

| 触发方式 | 动作 | 期次 |
|---|---|---|
| 转发触发 | 考察群聊天记录合并转发给它 → 启动一次批次加工 | 一期（现在能跑） |
| @指令 | "建批 周三 XX 项目四代宅" / "查四代宅对标" | 一期 |
| 定时巡检 | 每天扫批次控制表：该催的催、该关的关 | 一期 |
| 群消息回调 | 实时收群消息、自动归批 | 二期（需企微自建应用） |

一期就完整定义四种触发的语义；二期只是把"转发"换成"回调"，其余层不动。

### 编排层 · 批次状态机是大脑

```
意向 → 进行中 → 待整理 → 纪要草稿 → 待确认 → 已归档
```

- 每个状态定义超时与升级规则："待整理"超 24h 出声提醒，"待确认"超 48h @确认人
- **低打扰分寸控制**：同一件事 24h 内最多提一次；催两次无人响应转私聊负责人，不刷群

### 技能层 · 六个模块（各自可独立测试）

1. **素材解析**：聊天记录 → 结构化素材流（谁/何时/类型/内容）
2. **字段抽取**：素材流 + schema → 主表记录（带置信度，低阈值标"待人工核实"）
3. **纪要生成**：批次素材 → 纪要初稿（客观事实/主观判断/待核实三段式）
4. **背景包生成**：项目名 + 考察库历史 + 公开数据 → 一页纸背景包
5. **对标检索**：产品标签 → 横向对比视图
6. **表格读写**：所有落库操作，唯一持久化出口

### 工具层 · 连接器

企微消息、语音转写、图像理解、智能表格读写、联网检索。

### 人格与话术

定位是**"跟队实习资料员"**，不是"机器人"——实习生的姿态让人愿意纠正它。三原则：**短**（群内 ≤3 行，长内容转文档卡片）；**带出处**（结论标注来自哪张照片哪句话）；**敢说不知道**（置信度低就明说）。

## 2. 升级形态：持续收集 + 汇总出方案

批次版是"一次性工具"的局限：两次考察之间的群聊也是活的，观点碎片、转发文章、随口判断全在流失。升级为**持续生长的知识体**。

### 双智能体分工

| | 收集智能体 | 汇总智能体 |
|---|---|---|
| 角色 | 不睡觉的资料员（耳朵） | 出方案时的军师（大脑） |
| 工作模式 | 日常静默，识别·抽取·打标·增量入库 | 按需登场："@汇总 出 XX 四代宅定位建议" |
| 性格 | 静默无打扰 | 深度对话，人机迭代定稿 |

分两个而非一个的原因：收集要求静默、汇总要求深谈，两种模式互相干扰；且收集坏了不影响汇总，架构解耦。

### 分层知识库（整个设计的核心）

| 层 | 存什么 | 规则 |
|---|---|---|
| **事实层** | 可核实的硬数据（内外部） | 外部事实带可信度分级（A 政府原文 / B 门户与主流媒体 / C 自媒体传闻）；C 级不进方案正文 |
| **判断层** | 人的观点与结论 | **观点必带署名**——保留判断责任人与语境 |
| **偏好层** | 调教沉淀（口径/风格/判断标准） | 只能通过确认/纠偏流程写入 |

分水岭规则：**事实与观点分离、观点带署名**。"张总认为四代宅阳台半敞开更好卖"永远比"四代宅阳台半敞开更好卖"有价值。

### "调教"的本质

不是微调模型，是**偏好层记忆生长**。每次确认/纠偏写回偏好层，智能体每次开工先读它。换模型换平台，调教成果跟着资产走——比 fine-tune 便宜且透明可审计。

### 合规三道闸（持续收集的前提）

1. 入库前脱敏规则（人名、联系方式、敏感言论的默认策略与团队约好）
2. 收集范围默认"仅项目相关消息"，闲聊过滤
3. 成员知情同意（群公告写明"本群开启 AI 资料收集"）

## 3. 三智能体架构：加一只"眼睛"

**外部情报智能体**：定时巡航公开信息，独立于企微改造，最先可落地。

| 类别 | 信息源 | 抓什么 |
|---|---|---|
| 土地政策 | 自然资源局/规划局官网、政府公报 | 供地计划、计容规则调整、规划公示 |
| 房源动态 | 住建局网签公示、门户项目页 | 拿证、开盘、价格变动、去化描述 |
| 成本招采 | 公共资源交易中心、招标网 | 同类项目招标公告、材料价格指数 |
| 行业风向 | 官方公众号/媒体 | 四代宅/好房子政策解读、竞品动作 |

边界：**只做公开信息，不碰爬虫红线**。产出走文档卡片或独立情报频道，不占群聊。

**交叉印证是三智能体的化学反应**：外部"去化 90%"（B 级）+ 内部署名判断"去化好主要因价格策略" → 汇总时合成归因分析；外部发现计容规则调整 + 偏好层显示团队长期关注 → 主动推送。

## 4. 终极架构的缺件（补全清单）

| 缺件 | 解决什么 | 机制 | 建设时点 |
|---|---|---|---|
| **质疑守门员** | 幻觉拼接、过期数据、观点偏见漂移 | 汇总输出前强制环节：关键引用反查库内原记录、数字核对最新外部数据、观点核对署名；输出质量报告附方案后 | 第一版写死为架构约束 |
| **遗忘与保鲜** | 只进不出的库越用越蠢 | TTL（价格类一季度/政策类一年，到期转"待复核"）；替代链（新旧冲突时旧的标记"已被替代"，保留演化轨迹）；引用降权 | 第一版写死为架构约束 |
| **度量自省** | "好不好用"全靠感觉 | 持续度量：抽取准确率、纪要修改幅度、方案引用率、错题本（同一错误二次出现触发偏好层检查）；月度自省报告 | 跑起来后一个月内 |
| **执行的手** | 只产信息不执行动作 | 低风险动作自动（建批卡片/周报/导出），高风险动作出按钮等人点（对客发送/审批） | 按需生长 |

### 两条原则（非组件）

- **人的责任边界**：AI 出证据与草案，决策与签字永远是人。
- **退出权/数据主权**：客户随时可整库导出、随时可停用单个智能体不伤及其他。

## 5. 验收标准

| 层 | 验收信号 |
|---|---|
| 感知 | 一条转发记录，无需补充说明就启动加工 |
| 编排 | 一个批次从建批到归档，人只操作两次 |
| 技能 | 字段抽取准确率 ≥ 85%，纪要确认人改动 < 20% |
| 人格 | 有人愿意在群里@它问事情 |
| 记忆 | 删掉智能体重建，历史批次与资产完整无损 |
| 守门 | 每份方案带质量报告，引用反查零幻觉拼接 |

## 6. 产品设计缺件（2026-09-15 补）

系统缺件之外，产品血肉的缺口集中在"人这一侧"。按用户旅程审计：

| 旅程阶段 | 状态 | 缺什么 |
|---|---|---|
| 首次接触 | 缺 | **冷启动旅程**：历史资料导入引导（拍照/表格/AI 代整理）；**首个魔法时刻**——第一周必须让用户 wow 一次（建议：把去年考察的照片扔进去，48 小时内出一份"你考察过但可能忘了的项目"报告） |
| 日常使用 | 缺 | **高频触点**（考察与出方案都是低频事件，产品活着靠日常）：情报周报（每周一 9 点，5 分钟读完）、例会简报（月度例会前自动生成）、群内问答彩蛋 |
| 考察时刻 | 有 | 批次采集已设计（02 号文档） |
| 出方案 | 半缺 | **产出物形态**：上会页模板（对标矩阵+引用附录）、分享卡片、脱敏导出（把库变成能外发的材料的出口） |

### 贯穿全程的三个缺件

1. **角色与权限**（给谁用）：高管视图（只看结论与趋势）、投资经理视图（全库+对标工具）、资料员视图（治理界面）。敏感点：判断层可见性（某人的尖锐观点谁能看到）、调教权归属（谁能改偏好层）。
2. **纠错体验**（错了怎么办）：AI 一定会写错东西。设计三步：认错要快（"你说得对，已修正"）、修正要可见（改了哪条、影响了哪些下游）、**纠错即调教**（这次纠正自动沉淀为偏好，下次不犯）——把出错变成信任建设的契机而不是灾难。
3. **治理界面**（谁管它）：负责人需要偏好管理（调了什么、撤销）、合规开关（脱敏规则、收集范围）、知识库健康仪表盘（守门员与度量自省的可视化出口，就是给负责人的"驾驶舱"）。

### 未回答的元问题

**跨团队网络效应**要不要做：多个置业团队之间的数据对标网络（判断层互相可见、事实层脱敏共享）是网络效应的来源，但会改变产品性质（从工具到平台）与信任模型。这是产品方向级决策，留给 P2 讨论。

## 7. 演进路线

```
外部情报智能体（最先：不依赖企微改造，先把事实层喂起来）
  → 考察后批次整理（轻量版：转发触发）
    → 持续收集（二期：群消息回调 + 合规三道闸）
      → 汇总智能体（知识库有积累后登场，出方案=价值验证点）
        → 终极形态：+ 守门员 + 新陈代谢 + 镜子 + 手
```
